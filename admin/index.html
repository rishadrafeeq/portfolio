How publishing works

GitHub connection

Publishing saves your changes straight to your GitHub repo. Vercel redeploys automatically.

How to create the token (one time)

  1. Open GitHub → Settings → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → choose your portfolio repo.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Generate, copy the token and paste it above.

The token is stored only in this browser (localStorage) and is sent only to api.github.com. Use “Forget token” on shared computers.
